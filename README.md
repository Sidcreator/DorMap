# DorMap — система дорожных карт

Спецификация и инструменты для ведения дорожных карт проектов: глобальные ID задач, история изменений, HTML-отчёты, аудит самодостаточности.

Репозиторий содержит **обезличенные** артефакты: без путей, имён проектов и данных конкретных внедрений.

## Состав

| Файл | Назначение |
|------|------------|
| `План_СистемаДорожныхКарт_v18.md` | Полная самодостаточная спецификация (правила, форматы, код всех скриптов) |
| `roadmap_setup.py` | Установщик: все скрипты внутри, развёртывание одним запуском |
| `Чеклист_Самодостаточности_Плана.md` | Чек-лист аудита плана (A1–A33, B1–B12, C1–C11) |
| `План_СистемаДорожныхКарт_v12…v14.md` | Архив предыдущих версий |

## Развёртывание: 2 файла

```cmd
python roadmap_setup.py --root "<WORKSPACE>\ДорожнаяКарта" --project ProjectA --plan План_СистемаДорожныхКарт_v18.md
```

Установщик создаст структуру, скрипты (`new_task.py`, `sync_roadmap.py`, `validate_roadmap.py`, `check_plan.py`), конфиги (`projects.json`, `id_registry.json`, `tasks.json`) и выполнит первичную генерацию.

## Ежедневная работа

```cmd
python new_task.py --project ProjectA --name "Название задачи" --stages "Постановка;Реализация"
python sync_roadmap.py     # HTML + .md + журналы + правила из плана
python validate_roadmap.py # целостность ID/истории/отчётов
```

## Аудит плана

```cmd
python check_plan.py                                  # последняя версия плана
python check_plan.py План_СистемаДорожныхКарт_v18.md  # конкретная версия
```

Проверки: состав разделов, встроенный код и его синтаксис, отсутствие абсолютных путей и данных реальных проектов, согласованность §13.9 с кодом, манифест установщика.

## Версии
