# Чек-лист самодостаточности плана `План_СистемаДорожныхКарт_vN.md`

## D. Критерий готовности

Версия считается готовой, если:
1. `check_plan.py` — **PASS** (все A1–A33)
2. Все пункты B1–B12 отмечены ✅ (самодостаточность)
3. Все пункты C1–C10 отмечены ✅ (саморазвёртываемость)
4. В журнал версий плана добавлена запись о новой версии
5. Вывод `check_plan.py` приложен к задаче/сообщению как отчёт аудита

> При FAIL — исправить план и повторить аудит. Публиковать/использовать версию до PASS запрещено.

## E. Правила создания новой версии

### E1. Триггеры для создания новой версии

Новая версия плана создаётся при изменении любого из:

| Триггер | Пример | Требуется новая версия? |
|---------|--------|------------------------|
| Изменение структуры компонентов | Новый скрипт, новый JSON-файл | ✅ Да |
| Изменение формата данных | Новая схема `tasks.json`, новый тип события | ✅ Да |
| Изменение команд | Новая команда, изменение поведения команды | ✅ Да |
| Изменение формата отчёта | Новый CSS-класс, новая секция HTML | ✅ Да |
| Изменение правил нумерации | Новый формат ID, новый тип этапа | ✅ Да |
| Добавление/удаление раздела | Новый §N или удаление §N | ✅ Да |
| Изменение скриптов (логика) | Новый параметр `new_task.py`, новая проверка | ✅ Да |
| Изменение скриптов (стили) | Правка CSS в `sync_roadmap.py` | ❌ Нет (если структура не изменилась) |
| Обновление версий зависимостей | Python 3.12 → 3.13 | ❌ Нет |
| Исправление опечаток в документации | Правка текста в §1–§15 | ❌ Нет |
| Добавление примеров/комментариев | Новый пример в описании команды | ❌ Нет |

### E2. Процедура создания новой версии

1. Прочитать текущую версию (наибольший N)
2. Определить триггер (таблица E1)
3. Если триггер требует новую версию:
   - Создать `План_СистемаДорожныхКарт_v(N+1).md` — **полная самодостаточная спецификация** (не только изменения)
   - В журнал версий добавить строку `| **v(N+1)** |` с описанием изменений
   - Обновить ссылку «Предыдущий файл» на `vN`
4. Запустить `python check_plan.py` → **PASS** обязателен
5. Пройти чек-лист B1–B12 + C1–C10
6. Приложить вывод аудита к задаче/сообщению
7. При FAIL — исправить и повторить

### E3. Архивирование

- Предыдущие версии **не удаляются** и **не изменяются**
- Все версии хранятся в `ДорожнаяКарта/` как `План_СистемаДорожныхКарт_vN.md`
- Актуальная версия — файл с наибольшим N
- Старые версии доступны для исторической справки
